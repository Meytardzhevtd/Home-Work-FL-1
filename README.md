# Домашнее задание: Конечные автоматы

Проект реализует **недетерминированный конечный автомат (NFA)** с возможностью:
- чтения автомата из файла,
- симуляции работы на входной строке,
- преобразования NFA → DFA,
- записи результата в файл.
